# Remaining product extensions

The core and several advanced features are functional; these extensions are not simulated:

- Durable custom SVG asset hosting and automatic banner upload during publishing (SVG generation and download are implemented; host the asset separately).
- Pinned repositories through authorized GitHub GraphQL.
- A structured configuration-patch assistant (the current assistant proposes a full Markdown revision).
- Automatic regeneration of untouched sections while preserving manual edits in edited sections (the studio protects the whole draft with a review dialog; selected-section regeneration preserves all other sections).
- Diverse AI-authored full-document alternatives beyond the three visual variants using the same verified content.
- Authenticated per-account quotas and billing, distributed profile caching and retention jobs.
- Browser E2E and live PostgreSQL/OAuth/provider verification in a configured environment.

GitHub does not support arbitrary CSS/fonts in README files. Font controls apply to generated animated SVG headers only.
